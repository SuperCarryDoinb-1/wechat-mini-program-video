# 踩坑速查

按「看到的现象」查原因。

## 素材

| 现象 | 原因 | 处理 |
|---|---|---|
| 内容底部被整齐切掉一条 | 产品页在 375×760 视口下比视口高，截图只截了可视区 | 截之前把 iframe 调高（900），截 `body`，再裁尾部空白 |
| 画面左右各有一条细黑线 | 预览页 `iframe{border:1px}` 被截进图 | 绘制时裁 4px（@3x），或截图后统一裁边 |
| 缩放后四周露白边 | 卡片底色是白色，页面底色是奶油色 | 卡片内层填充改用截图的页面底色 |
| 短页面看起来"内容很小、下面一大片空" | 按最长页统一缩放 | 改为按页适配 `min(宽比, 高比)`，代价是长页小 5% |

## 翻页 / 动效

| 现象 | 原因 | 处理 |
|---|---|---|
| 奔跑的小人被横切一刀 | 抠出来的精灵图自带旧进度条 | 不要抠图重绘；表头直接用每页原图，交叉淡入 |
| 抠掉旧条后小人断成两截 | 精灵图的头/腿被旧条分隔成两个连通块 | 同上，放弃抠图 |
| 进度条跟着页面一起滚走 | 把整个页面当作内容在滚动 | 表头固定：单独裁出表头区域，内容只滑动表头以下 |
| 换页瞬间新旧两页叠在一起发虚 | 交叉淡入 + 模糊，两页同时半透明 | 改成「旧页上滑淡出 → 空档 → 新页滑入」，或用整屏上滑 |
| 连续滚动看得头晕 | 6 秒滚 11 个屏高，约 2600px/s | 改成一页一停（1.1s）+ 上滑 0.36s 吸附 |
| 验收报 `frozen ≥ 0.8s` | 停留期间整页完全静止 | 加 1–1.2% 落定回缩；或让元素有轻微起伏 |
| 文字被平台 UI 盖住 | 字幕/计数落在上下 12% 安全区 | 跑 `--text-check`，把文字挪进安全区 |
| 内容贴住卡片下边缘 | 裁剪区高度 = 卡片高 − 表头（没留底） | 底部留白 ≈ 38px（1080 宽） |

## 音乐 / 声音

| 现象 | 原因 | 处理 |
|---|---|---|
| 播放器没声音、时长 NaN | 合成器默认输出 24-bit PCM WAV，浏览器不支持 | 转 MP3（libmp3lame 192k）再放进网页 |
| 网页里音频"什么都没" | 给的是本地文件路径而非 http 链接 | 用 `http://127.0.0.1:<port>/...` 打开 |
| `inspect.mjs qa` 报真峰值 FAIL（如 +0.1 dBTP） | AAC 编码会抬高峰值的样本间插值 | 导出后用 `alimiter=limit=0.82` 重封音频 |
| 用户嫌"太电子" | 合成器默认音色偏电子 | 换现成曲子（Incompetech 直链可用，Pixabay 需站内下载） |
| 交付被问版权 | 用了 CC BY 曲子 | 说明里加：`Music: "<曲名>" — Kevin MacLeod (incompetech.com), CC BY 4.0` |

## 流程 / 环境

| 现象 | 原因 | 处理 |
|---|---|---|
| `ffmpeg not found on PATH`（子进程里） | Git Bash 的 Windows 风格 PATH 不生效 | 用 `/d/...` 形式 export |
| 首次渲染立刻拿到白帧 | 页面在图片/字体就绪前就开始画 | 模块开头 `window.READY = false;`，boot 完成再置 true |
| 字体报错 "Could not resolve ... as a font" | `document.fonts.load` 传了系统字体族 | 只 load 自托管的 @font-face，系统字体不用 load |
| 改完时长忘了重裁音频 | 音画不同步 | 每次改 `DUR` 都重新裁曲、重跑 `build.sh` |

## 沟通

| 现象 | 处理 |
|---|---|
| 用户说"信息量太低" | 先列信息点清单（几屏、几个功能、几个人设），再决定时长；通常要加内容而不是加特效 |
| 用户对开场/结尾"不满意"但说不清 | 做成 HTML 方案页，每个选项都是真实在动的 9:16 小样，让用户点选 |
| 用户说"不高级" | 多半是整屏只有一处在动，或只有 logo 出场；检查是否"内容在演"，而不是加粒子 |
| 用户说"被切了/贴边了" | 先确认素材是不是本来就被裁了（量视口高度），再谈缩放 |
